# Model runtime: ONNX. This is what actually works.
#
# The delivered .tflite carries 800+ TF Select ("Flex") operators
# (tools/inspect_tflite_ops.py). No stock TFLite interpreter can resolve those:
# not react-native-fast-tflite on a phone, and not even the full TensorFlow
# wheel on Windows, which ships no Flex delegate library at all. Converting to
# ONNX removes the problem — Flex ops ARE TensorFlow ops, so tf2onnx maps them
# to standard ONNX operators. Result: ~100 ms per image on CPU, and no
# TensorFlow at runtime.
#
# Do NOT add tflite-runtime as an alternative; it has no Flex delegate either.
onnxruntime==1.28.0
